# Baseline Use Rule

Participating models should examine the commit-specific repository whenever their interface permits.

If a model cannot access the commit-specific view and can examine only the live `main` branch, it must:

1. exclude the entire `Repository-Utility-Studies/` directory from its evidential corpus;
2. state that it used the live repository rather than the frozen commit;
3. describe any access limitations;
4. avoid citing study-generated materials as CompassionWare evidence;
5. avoid implying direct comparability with models that successfully examined the frozen baseline without noting the difference.

If a model cannot reliably inspect either the frozen commit or the live repository, preserve that failure as part of the study. A common fallback source package may be developed later, but any model receiving that package must be labeled separately from direct-repository readers unless all comparable models are rerun with the same package.
