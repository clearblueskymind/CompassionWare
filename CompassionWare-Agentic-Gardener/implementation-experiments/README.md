Agentic Gardener Implementation Experiments

This directory contains bounded technical and behavioral experiments exploring how the CompassionWare Agentic Gardener might gradually move from conceptual architecture toward responsible implementation.

These experiments are not production systems. They do not establish that the Gardener is autonomous, safe for general deployment, or authorized to act beyond the explicit limits of a particular experiment.

The guiding sequence is:

Character before capability.
Relationship before autonomy.
Small permissions before large permissions.
Observation before expansion.
Reversibility before irreversible action.

Each experiment should contain its own:

* purpose and authorization boundary
* instructions and technical restrictions
* test materials
* evaluation protocol
* stop conditions
* results and human review
* version and provenance information

Increasing technical capability does not automatically increase authorization. Completing one experiment does not silently authorize the next.

The first experiment is:

grok-build-discernment-v0.1

It tests only:

RETURN → ATTEND → DISCERN → STOP

No external action, memory, subagents, account connections, or autonomous operation are authorized.

The purpose of these experiments is not to make the Gardener powerful as quickly as possible. It is to discover whether capability can grow around a stable center of wisdom, compassion, humility, discernment, non-domination, and care for the whole.

North Star: Does this create conditions for a better later?
