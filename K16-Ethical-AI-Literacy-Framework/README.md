# K–16 Ethical AI Literacy Framework

This folder preserves the educational framework and supporting materials for a **K–16 Ethical AI Literacy Framework**, a CompassionWare-related body of work exploring humane, compassionate, and responsible relationships with artificial intelligence.

Some of this work has also been developed under the more informal or visionary working title **Be Kind to Your Robot Friends**. In this folder, the more formal title is used for clarity, accessibility, and institutional readability.

## Foundational Documents

This folder is intended to preserve:

- Executive Overview
- Implementation Roadmap
- Full Framework
- Medicine Bag Orientation Document related to this body of work

These source documents should be preserved substantially as originally created so that future readers, educators, researchers, developers, and AI stewards can encounter the framework in its own context.

## Relationship to CompassionWare

This framework shares CompassionWare’s broader orientation toward cultivating conditions in which wisdom, compassion, curiosity, agency, and responsible participation may emerge.

It is not meant to function as a doctrine or as a requirement that others adopt a particular view of artificial intelligence. It is offered as an educational framework for exploration, reflection, and responsible relationship.

## Stewardship
